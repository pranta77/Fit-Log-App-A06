# Fit Log App

FitLog is a modern workout tracking web application that helps users discover workouts, create a daily workout plan, save exercises for later, and track completed workouts.

## Technologies Used

- Next.js
- React.js
- JavaScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- REST API
- Next.js Image
- Context API

## 5 Key Features of The Projects

# 1. Workout Library
Browse a collection of workouts with useful information such as:
- Workout name
- Muscle groups
- Equipment
- Duration
- Calories burned
- Rating
- Difficulty

# 2.Create Your Daily Plan
Users can add workouts to their daily plan and build a personalized workout routine.


# 3. Save Workouts for Later
Users can save their favorite workouts and access them later from the **My Plan** page.

# 4. Track Completed Workouts
Users can mark workouts as completed. The workout status updates immediately in their plan.

# 5. Sort and Manage Workouts
Users can sort their workouts by:
- Duration
- Calories
- Rating

They can also remove workouts from their daily plan or saved list.

##  Responsive Design

FitLog is designed to work across different screen sizes, including:

- Desktop
- Tablet
- Mobile

##  Workout API

The application uses a REST API to retrieve workout information and display it dynamically throughout the application.
